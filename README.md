# Intel: Sustainability Through the Ages

An interactive timeline that tells the story of Intel's sustainability journey, from the company's founding in 1968 to its commitment to net-zero emissions by 2040.

**🔗 Live site:** https://dishaabhat08.github.io/02-prj-intel-sustainability/

## About

This project shows nine key moments in Intel's history as a scrollable timeline, starting with the first microprocessor and ending with its 99% renewable electricity milestone and first Sustainability Summit. Each card shows a short summary, and more detail appears when a visitor hovers over the card or reaches it with the keyboard.

## Features

- **Interactive timeline cards:** hover or focus a card to show more detail, with smooth transitions
- **Horizontal scroll snap:** cards snap into place as you scroll through the timeline
- **Responsive design:** the layout switches to a vertical stack on mobile screens
- **Accessibility:** a skip link, keyboard-focusable cards, and support for reduced-motion preferences

## Built With

- HTML5
- CSS3 (Flexbox, transitions, scroll snap, media queries)

## What I Learned

- Building interactive effects with CSS alone, using hover and focus states
- Designing a layout that works on both desktop and mobile
- Making interactive content accessible to keyboard users and people who prefer reduced motion
